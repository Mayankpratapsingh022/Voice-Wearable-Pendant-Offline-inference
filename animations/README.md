# Approved pendant animations

This is the only animation directory committed to the repository.

- `moon/moon-final.gif` is the approved moon-loop preview.
- `orbital/orbital-strands-final.gif` is the approved orbital-strands preview.
- `orbital/esp32-frames/` contains the A8 LVGL frame payloads used by the
  ESP32's flash asset partition. These frames are required for the live
  orbital loop; they are not temporary render output.

All animation experiments, source workspaces, contact sheets, temporary
frames, MP4 exports, and renderer caches belong under `videos/` and are ignored
by Git.
